
# Rafeeq in Production - Capstone Project
Submitted by : Ruba Hasan Fahad
Course: Advanced Agentic AI systems Engineering - SDAIA Academy 

## Project Overview
Rafeeq is a production-ready AI assistant service built as part of the SDAIA Academy Advanced Agentic AI Systems Engineering Capstone. It implements advanced agentic patterns including Model Context Protocol (MCP), secure memory retrieval, step and cost budgeting, write approvals, and rigorous evaluation pipelines.

## Features & Architecture
- **Advanced Tools & MCP**: Integrates multiple core tools along with Model Context Protocol for secure context sharing.
- **Memory & Retrieval**: Persistent context and historical memory management.
- **Governance & Safety**: Implements strict budget rules (step and cost tracking) and explicit human-in-the-loop approvals on write operations.
- **Evaluation Suite**: 15+ automated evaluation tasks with configuration comparisons and error analysis.
